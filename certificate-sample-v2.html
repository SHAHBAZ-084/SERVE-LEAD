What changed in this v2 pass (more depth / shading)

  • Card shadow — the whole certificate now casts a soft, layered drop shadow (two shadow layers) so it reads as a physical object sitting above the page, not a flat rectangle.
  • Left rail is embossed — added a diagonal sheen overlay + inset highlight/shadow so the navy rail looks like brushed metal/leather rather than a flat color block.
  • Title uses a gradient fill — "CERTIFICATE" is now a subtle navy gradient with a 1px light text-shadow underneath for a lightly engraved look.
  • Gold underline beneath the name now fades gold→light gold→gold with its own soft shadow, instead of a flat 1px line.
  • Seal got a radial gradient fill + drop shadow so it sits "above" the paper instead of looking pasted on.
  • Double ornamental frame (outer hairline + inner gold hairline) was added around the whole content area — common on premium certificates, gives it an official, bordered feel without being a thick, heavy box.
  • Logo badge now has an inner highlight + inner shadow (top-light, bottom-dark) so it reads as a raised badge, not a sticker.
  • Vignette overlay — a very faint radial darkening toward the edges focuses the eye toward the center content, the same trick used on printed certificates and currency.
